## Run Locally

The portfolio is a static website and does not require a backend server.

Using Python:

```bash
git clone https://github.com/bsathwik-cyber/portfolio.git
cd portfolio
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

You can also open `index.html` directly in a browser, although using a local server is recommended for testing.
